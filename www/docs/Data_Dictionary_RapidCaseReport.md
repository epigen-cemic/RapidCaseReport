# Data Dictionary – RapidCaseReport v2.0

This dictionary describes the standard `reports` structure used by RapidCaseReport v2.0.

The local SQLite file is an internal app data store. It should not be exposed to end users as a downloadable database. Users may download only the records submitted during the current active session.

## Standard table

| Item | Value |
|---|---|
| Standard table name | `reports` |
| Purpose | Stores confirmed suspected-case reports submitted through the form |
| Primary identifier | `id_code` |
| User-facing download | Current-session CSV only |

## Fields

| Field name | Type | Format / allowed values | Required | Description |
|---|---:|---|---:|---|
| `id_code` | Text | UUID | Yes | Autogenerated unique identifier for each confirmed submission. |
| `consultation_date` | Date | `YYYY-MM-DD` | Yes | Date of consultation or reporting contact. |
| `sex` | Text | `Male`, `Female`, `Other`, `Prefer not to say` | Yes | Sex/category selected in the form. |
| `birth_date` | Date | `YYYY-MM-DD` | Yes | Date of birth. |
| `country` | Text | Configured country | Yes | Country selected in the location module. |
| `level1` | Text | Configured geography label/value | Yes | First configured geographic level. For Argentina this is Province. |
| `level2` | Text | Configured geography label/value | Yes | Second configured geographic level. For Argentina this is Department. |
| `level3` | Text | Configured finest-level ID/value | Yes | Third configured geographic level. For Argentina this is Censal Fraction. |
| `symptom_onset_date` | Date | `YYYY-MM-DD` | Yes | Date when symptoms began. |
| `symptom_description` | Text | Free text | Yes | Description of symptoms. |
| `suspected_diagnosis` | Text | Free text | Yes | Suspected diagnosis or event label. |
| `confirmation_time` | Date-time | `YYYY-MM-DD HH:MM:SS` | Yes | Timestamp created when the user confirms submission. |
| `submitted_at` | Date-time | `YYYY-MM-DD HH:MM:SS` | Yes | Submission timestamp used for display/export. |
| `email` | Text | Email address | Yes | Reporting professional email. |
| `institution` | Text | Free text | Yes | Reporting institution or organization. |

## Geography notes

RapidCaseReport v2.0 uses generic geography names in storage:

| Generic field | Argentina label |
|---|---|
| `country` | Country |
| `level1` | Province |
| `level2` | Department |
| `level3` | Censal Fraction |

Display labels and spatial mappings are controlled by `config.json`.

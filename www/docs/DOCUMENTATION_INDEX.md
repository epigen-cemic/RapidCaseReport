**Publication note:** the source does not contain admin-password downloads, email-based historical exports or generalized external database connectivity. The visible badge is `2.0.0` in `config.yaml`; citation metadata identifies software `2.0.1`. Reconcile before a formally approved release. Roxygen2 blocks in `R/` describe named functions.

The accompanying Word guides follow the Analysis for Action branding and editorial style guide. Documentation is written in British English. An institution distributing these guides externally should check local branding and funder acknowledgements before publication.

# RumorForm WP1.1 – Suspected Case Reporting Tool

**Version:** `v20250624`  
**Live app:** [https://epigen.shinyapps.io/rumorform_v20250624](https://epigen.shinyapps.io/rumorform_v20250624)

## 📌 Overview

RumorForm is a rapid data entry tool built in R/Shiny to report suspected disease events ("rumors"). It was developed as part of the PPT-UK Project (Argentina Work Package WS5).

## 🚀 Features

- Autogenerated case ID
- GeoNames API integration for location fields
- ICD-10 and HPO fields
- CSV download of submissions
- Fixed SVG background design (CEMIC)

## 📦 Installation

### Requirements

- R >= 4.2
- RStudio recommended
- R packages:
  ```r
  install.packages(c("shiny", "dplyr", "uuid", "httr", "jsonlite", "rsconnect"))
  ```
- Downgrade Rcpp to compatible version:
  ```r
  install.packages("remotes")
  remotes::install_version("Rcpp", version = "1.0.11")
  ```

### Folder Structure

## ▶️ Run Locally

```r
setwd("path/to/RumorForm_v20250624")
shiny::runApp()
```

## ☁️ Deploy to shinyapps.io

```r
install.packages("rsconnect")
rsconnect::setAccountInfo(name='your_name', token='your_token', secret='your_secret')
rsconnect::deployApp()
```

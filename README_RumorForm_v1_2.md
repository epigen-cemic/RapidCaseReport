# RumorForm WP1.1 - Rapid Reporting Form for Suspected Cases

**Version:** v1_2  
**Deployment:** [https://epigen.shinyapps.io/rumorform_v1_2/](https://epigen.shinyapps.io/rumorform_v1_2/)

## Description

This Shiny application is part of the Argentina Work Package WS5 (WP1.1) within the PPT-UK project. It serves as a structured digital form for reporting suspected health events ("rumors") with minimal delay. It collects individual, symptomatic, and diagnostic data.

## Features
- Autogenerated unique report ID
- GeoNames API integration for dynamic country/province/locality selection
- HPO and ICD-10 code fields
- CSV download of all submitted reports
- Fixed background image (PPT-CEMIC SVG)

## Run Locally

### Requirements
- R (version >= 4.2.0)
- RStudio (recommended)
- Installed packages:
  ```r
  install.packages(c("shiny", "dplyr", "uuid", "httr", "jsonlite", "rsconnect", "leaflet", "shinyjs", "here", "arrow"))
  ```
- **Rcpp version 1.0.11** is required:
  ```r
  install.packages("remotes")
  remotes::install_version("Rcpp", version = "1.0.11")
  ```

### Folder Structure
```
RumorForm_v1_2/
├── app.R
└── www/
    └── PPT_cemic_images.svg
    └── config.css
└── R/
    └── modules.R
└── raw_data/
    └── geografic data.gpgg
```

### Run the App
```r
setwd("path/to/RumorForm_v1_2")
shiny::runApp()
```

## Deploy to shinyapps.io
1. Get a free account at [https://www.shinyapps.io](https://www.shinyapps.io)
2. Install and configure `rsconnect`:
   ```r
   install.packages("rsconnect")
   rsconnect::setAccountInfo(name='your_name', token='your_token', secret='your_secret')
   ```
3. Deploy:
   ```r
   rsconnect::deployApp()
   ```
